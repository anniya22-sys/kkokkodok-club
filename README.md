# 콘텐츠 비서 Agent — 시작 템플릿

생성형 AI 활용 & 바이브코딩 마스터 3기 · 3~4주차 실습용

## 폴더 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 공개 페이지 (브랜드 소개 + 콘텐츠 목록) |
| `admin.html` | 관리 페이지 (제안함·초안 검수·쓰레드 변환·기록) |
| `assets/data.js` | 브랜드·콘텐츠 데이터 (3주차 예시 데이터) |
| `assets/style.css` | 디자인 |
| `assets/app.js` | 화면 동작 |
| `posts/` | 발행 완료된 원문 페이지 (4주차) |
| `PRD.md` | 무엇을 만들지 적는 기획서 |
| `CLAUDE.md` | Claude가 지킬 작업 규칙 |

## 3주차 순서
1. `PRD.md` 작성 (Claude에게 인터뷰 요청)
2. `CLAUDE.md`의 브랜드 항목 작성
3. `assets/data.js`의 BRAND를 내 정보로 변경
4. 말로 기능 1개 바꾸기 (예: 섹션 추가, 색 변경)
5. GitHub 비공개 저장소에 올리고 Netlify 연결
6. **연동 시험:** 문구 1줄 수정 → push → 같은 주소에서 변경 확인

## 관리 페이지
- 3주차: 예시 데이터로 동작하는 연습 모드 (아무 코드나 입력하면 입장)
- 4주차: Apps Script에서 접근 코드 확인

## 보안 기준
- 저장소는 비공개(Private)로 생성
- 배포된 화면 코드는 누구나 볼 수 있으므로 API 키·접근 코드는 Apps Script에 보관
